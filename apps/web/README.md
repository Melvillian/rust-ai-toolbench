# web

Minimal Dioxus 0.7 single-page app (client-side WASM + router + Tailwind v4).
Deployed in production as a Render static site from `dist/public`
(`dx bundle --release --out-dir dist`), with an `/api/*` rewrite proxying to
`apps/api` (see the `render-deploys` skill); in dev, the `dx serve` proxy
forwards `/api` and `/health` to axum on :8080.

## Commands (run from repo root)

- `cargo dev` — start axum (:8080) and `dx serve` with hot reload (:5173) together
- `cargo dev-web` — Dioxus dev server alone
- `cargo start` — build everything, then run api (:8080) + this app via `cargo preview` (:4173)
- `cargo test -p web` — run this app's tests
- `cargo clippy -p web --all-targets -- -D warnings` — lint this app

No env setup is needed for `cargo dev` or `cargo start`: the api defaults to
:8080, the port the `Dioxus.toml` proxy targets (`cargo preview` uses the same
proxy config, mirroring the static site's prod `/api/*` rewrite). If you set a
different `PORT` in `apps/api/.env`, update the `[[web.proxy]]` backends in
`Dioxus.toml` to match.

## Structure

- `src/main.rs` — entrypoint: mounts the stylesheet and `Router`
- `src/app.rs` — layout shell (nav + `Outlet`)
- `src/routes.rs` — route table: **add new pages here**
- `src/pages/` — one component per route
- `tailwind.css` — Tailwind v4 entry; `assets/tailwind.css` is generated by `dx`

## Extending

- New page: add `src/pages/foo.rs`, export it from `src/pages/mod.rs`, add a
  `#[route("/foo")] Foo {}` variant in `src/routes.rs`, link it from `app.rs`.
- New API call: fetch relative paths (`/api/...`) — rewritten to the api
  service in prod, proxied in dev. Add new `[[web.proxy]]` entries in
  `Dioxus.toml` (and matching rewrites in `render.yaml`) if you add API
  routes outside `/api`.
- Crates: `cargo add <crate> -p web` (browser-only crates go under
  `[target.'cfg(target_arch = "wasm32")'.dependencies]`).
